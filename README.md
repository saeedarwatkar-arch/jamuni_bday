# Jamuni Birthday Surprise 🎀

A responsive React + Vite birthday surprise for Supriya aka Jamuni. Birthday: **11 October 2006** (turning 20 on 11 October 2026).

## Run locally
1. Install Node.js (LTS) if it is not installed.
2. Extract this folder and open a terminal in it.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Personal photos included
Your nine uploaded photos are already included in `public/photos/` as `memory-1.png` through `memory-9.png`. The memories gallery displays them automatically. You can replace a photo by keeping the same filename, or change the image paths and captions in `src/main.jsx`.

## Notes
- The layout is responsive for laptops, tablets, and phones.
- The music button plays a built-in, gentle chiptune melody using the browser Web Audio API; no external audio file is needed. Click “Play music” to start or “Music on” to stop. Browsers require a user click before sound can begin.
- This is a playful fan-made Shinchan-inspired design, not an official or affiliated site.
- To publish it, you can deploy the Vite project to a static hosting provider such as Netlify or Vercel.
